# Project 04 — Machine Language

Hack assembly programs for multiplication, screen filling, and swapping values.

## Tools

CPU Emulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

Load the tests in `mult/`, `fill/`, and `swap/` into the CPU Emulator. Inspect each assembly file for its input assumptions. Original `_org` folders are retained.
