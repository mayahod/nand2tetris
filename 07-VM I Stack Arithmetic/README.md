# Project 07 — VM I: Stack Arithmetic

Translation of stack arithmetic, logic, comparisons, and memory-segment access from VM commands to Hack assembly.

## Tools

Python 3 and CPU Emulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

From the repository root:

```sh
python "07-VM I Stack Arithmetic/Main.py" "07-VM I Stack Arithmetic/StackArithmetic/SimpleAdd/SimpleAdd.vm"
```

The assembly file is written beside the input. Use the corresponding CPU Emulator `.tst`/`.cmp` fixtures. This stage does not implement function calls.
