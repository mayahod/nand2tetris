# Project 09 — High-Level Language

Jack language examples and supporting graphics utilities supplied with the coursework.

## Tools

Jack Compiler and VM Emulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

Compile a complete example directory, such as `Square/`, with the course Jack Compiler, then load that directory in the VM Emulator. `Main.jack` at this folder root is an unimplemented starter template, not a finished application. The image converter additionally imports NumPy, Pillow, pyperclip, and bitstring; it is a course utility credited in its source.
