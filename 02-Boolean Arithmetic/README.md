# Project 02 — Boolean Arithmetic

Half/full adders, a 16-bit adder, incrementer, ALU, and course shift extensions.

## Tools

Hardware Simulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

Run `HalfAdder.tst`, `Add16.tst`, and `ALU.tst`. The shift chips require the compatible Hebrew University tool distribution.
