# Project 10 — Compiler I: Syntax Analysis

A Python Jack tokenizer and recursive syntax-analysis engine that emit XML parse trees.

## Tools

Python 3 and course TextComparer. Use the compatible course distribution for Hebrew University extensions.

## How to run

From the repository root:

```sh
python "10-Compiler I Syntax Analysis/JackAnalyzer.py" "10-Compiler I Syntax Analysis/Square"
```

The analyzer writes `.xml` files beside `.jack` files. Copy the sample directory first if you want to preserve the supplied XML fixtures. Compare generated XML with the reference using TextComparer. This is syntax analysis; it does not generate VM code.
