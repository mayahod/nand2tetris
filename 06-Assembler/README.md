# Project 06 — Assembler

A two-pass Python assembler that resolves labels and variables and emits 16-bit Hack instructions, including shift instructions.

## Tools

Python 3. Use the compatible course distribution for Hebrew University extensions.

## How to run

From the repository root:

```sh
python "06-Assembler/Main.py" "06-Assembler/add/Add.asm"
```

This writes `Add.hack` beside the input. A directory argument processes its immediate `.asm` files. Use the CPU Emulator to run the result.
