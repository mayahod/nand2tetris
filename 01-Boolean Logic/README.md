# Project 01 — Boolean Logic

Logic gates, multiplexers, and demultiplexers implemented in HDL.

## Tools

Hardware Simulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

Load a supplied `.tst` file, such as `Not.tst`, in the Hardware Simulator and run it against its `.cmp` file.
