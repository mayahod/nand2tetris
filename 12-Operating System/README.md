# Project 12 — Operating System

Jack OS class interfaces, pseudocode, and test programs for arrays, memory, math, strings, screen, keyboard, output, and system services.

## Tools

Jack Compiler and VM Emulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

This folder is retained as an unfinished course scaffold: OS method bodies are largely empty. The supplied tests describe the intended behavior, but this folder is not a working replacement for the built-in OS. Use the course-provided OS for running other Jack examples until these implementations are completed.
