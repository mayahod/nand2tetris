# Project 03 — Sequential Logic

Bit storage, registers, the program counter, and hierarchical RAM chips.

## Tools

Hardware Simulator. Use the compatible course distribution for Hebrew University extensions.

## How to run

Use the tests in `a/` for registers and smaller RAM chips and `b/` for larger RAM chips. The original `_org` directories are retained as course reference material.
